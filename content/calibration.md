# calibration.md — 難度キャリブレーション基準(WP2)

opera-italian-reader のパッセージ生成が満たすべき難度・文体・文法の基準。SPEC v1 §4.1(パッセージJSONスキーマ)・§4.2(誤読タイプenum)・§2(訓練フェーズ)に従属する。生成手順そのものは `content/GENERATION.md`、機械的検証は `content/validate.mjs`。

- 対象試験: 東京藝術大学大学院 音楽研究科 伊語筆記(2題の全文和訳・90分・紙辞書持込可)
- 想定水準: 大卒程度、CEFR B1〜B2
- 学習者の自己申告の弱点: **一文の長さ**(長い複文の構文分解)。したがって難度の主軸は語彙の希少性ではなく**構文の入れ子と挿入の深さ**に置く。

---

## 1. 出題の実測プロファイル(過去2年)

出典は過去問PDF(`wp2/sources/`)に明記されている。**本文は著作権により過去問にも掲載されておらず、本プロジェクトでも原文の複製・翻案は行わない**。以下は出典書誌から確定できるジャンル・文体の特徴の記述に限る。

| 年度 | 問 | 出典 | ジャンル | 文体の特徴 |
| --- | --- | --- | --- | --- |
| 2025 | 1 | *La moda. Usi e costumi del vestire*(Electa Gallimard, 1996, p.14) | 服飾文化の解説書 = **essay(説明文)** | 中立的・記述的な現在形。定義と分類の文。名詞化と抽象名詞が多く、関係節で定義を積み増す。専門語は文脈から絞り込める種類のもの |
| 2025 | 2 | Italo Calvino *Sotto il sole giaguaro*(Garzanti, 1986, p.61) | 文学的物語 = **narrative** | 語り手の一人称・知覚の記述。長い列挙、コロン/ダッシュによる展開、比喩。時制の交替(半過去と遠過去/近過去)と代名詞の照応が読解の要 |
| 2026 | 1 | Sebastiano Vassalli *Gli italiani sono gli altri*(1998) | 現代エッセイ = **essay** | 論争的・一人称複数(noi)を含む論述。譲歩(eppure, tuttavia)と相関構文(non… ma/bensì)、接続法を伴う主張動詞(sostenere, ritenere che…) |
| 2026 | 2 | Nessia Laniado *Tutte le frasi che fanno infuriare i nostri figli*(2005) | 育児実用書 = **practical** | 平明な語彙・助言の口調(conviene, basta, è utile)。会話の引用句が地の文に埋め込まれる。非人称のsiと一般人称のchiが頻出 |

**確定した出題傾向**:

1. 2題は「説明文・エッセイ系1題 + 物語・文学系1題」の組合せ。音楽トピックには限定されない。
2. いずれも**現代イタリア語の散文**(1986〜2005年)。古語・韻文・オペラのリブレット的語法は出題対象外。
3. 語彙の絶対的な難しさより、**一般教養的な話題を長い文で述べる**タイプ。紙辞書が持込可であることは、「引けば分かる語」は障害と見なされていない = 差がつくのは構文であることを意味する。

→ 生成方針: **ジャンル配分は essay : practical : narrative = 2 : 1 : 1 程度**、トピックは一般教養から広く取り、音楽は全体の1〜2割に留める。

## 2. 難度を決める4変数

| 変数 | 定義 | 測り方 |
| --- | --- | --- |
| W | パッセージ総語数 | 空白区切りトークン数(`validate.mjs` の `tokenize` が唯一の定義) |
| Lmax | 最長文の語数 | 同上、文ごと |
| S | 1文あたりの平均従属節数 | `sentences[].clauses` のうち type が rel/sub の数の平均(insとgerは節ではないので別に数える) |
| D | 挿入の深さ | 主語と述語の間、または動詞と目的語の間に割り込む要素(ins)の最大語数 |

語彙の希少度は難度変数に**含めない**(紙辞書可のため)。ただし `vocab[].hint` で「辞書を引くべき/推測可」を必ず分類し、辞書を引く判断そのものを訓練対象とする。

## 3. フェーズ別の定量目標

| | P1(〜2026-12) | P2(2027-01〜06) | P3(2027-07〜) |
| --- | --- | --- | --- |
| W(総語数) | **100〜130** | **180〜250** | **1題175〜225、2題で計350〜450** |
| Lmax(最長文) | **25〜35語** | **40〜60語** | 40〜70語 |
| 文数 | 4〜6 | 6〜8 | 1題あたり6〜8 |
| S(rel+sub の平均/文) | **1.0〜1.8** | **1.8〜2.8** | 1.8〜2.8 |
| 最長文の従属節数 | 2〜3 | **3〜5**(関係節・従属節の多重化) | 3〜5 |
| D(挿入の最大語数) | 2〜5 | **6〜12** | 6〜12 |
| 段落 | 1〜2 | 2〜3 | 2〜3 |
| 想定所要 | 部分訳10〜15分 | 全訳25〜35分 | 2題90分(1題40分+見直し10分) |

`validate.mjs` は W と Lmax をフェーズ別レンジと突き合わせ、逸脱を **WARN** として出す(FAILにはしない。意図的な逸脱を人が判断できるようにするため)。S と D は自動判定せず、下の検品チェックリストで人が見る。

**段階スケールの運用**(SPEC §2「文長を段階スケール」):P1期は Lmax を 25 → 30 → 35 と月単位で上げ、12月時点で P2 の下限(40語)に接続する。P1の早い時期のパッセージから配信し、Lmax の昇順に消化する。

## 4. 文法要素の出現目標

「1本のパッセージに必ず含める(必須)/どれか複数を含める(選択)」の別で管理する。**必須要素は文法のためだけに不自然に埋め込まない**。自然に入らないならトピックを変える。

### 全ジャンル共通(必須)

| 要素 | P1 | P2 |
| --- | --- | --- |
| 関係節(che / cui / 前置詞+cui) | 2か所以上 | 4か所以上。うち1か所は**主語と述語を隔てる**位置に置く |
| 接続法(現在または半過去) | 1か所以上 | 2か所以上 |
| 挿入句(コンマ・ダッシュで括られる要素) | 1か所以上 | 3か所以上 |
| 代名詞の照応(lo/la/le/gli/ne/ci、所有 proprio) | 3か所以上 | 5か所以上。少なくとも1つは**先行詞が2文以上前** |
| 過去分詞句・ジェルンディオ句 | 1か所以上 | 2か所以上 |

### ジャンル別(必須)

- **narrative**: **遠過去(passato remoto)を必須**。半過去との対比を必ず作る。過去未来(condizionale composto: sarebbe venuto / avrebbe trovato)を1か所以上。come se + 接続法半過去/大過去を1か所以上。
- **essay**: 主張動詞 + che + 接続法(sostenere / ritenere / sembrare che…)を1か所以上。受動態を1か所以上(**essere受動と venire受動を書き分ける**)。相関構文(non… ma / bensì、più… che、sia… sia)を1か所以上。
- **practical**: 非人称の si と一般人称の chi を各1か所以上。conviene / basta / è utile 型の非人称構文を1か所以上。仮定文(se + 接続法半過去 → 条件法現在)を1か所以上。

### 意図的に仕込む「罠」(`sentences[].traps` と対応)

各文に traps を1〜3個付ける。仕込みは以下の型に限る(SPEC §4.2 のenumと1対1):

| code | 仕込み方 |
| --- | --- |
| SYN | 主語と動詞を長く隔てる / 動詞のあとに主語を置く / 等位の主節を1文に2つ入れる |
| MOD | 過去分詞句・形容詞句の一致(性数)を手がかりにしないと修飾先を誤る配置にする |
| REF | 同一文内に人称代名詞を2つ以上置き、指す相手を分ける(例: le = 彼女に、la = 彼女を) |
| MOOD | 接続法・条件法・過去未来・虚辞のnon(finché non)を使い、時制の読み違いが訳文に出る形にする |
| LEX | 多義語・成句(comune「自治都市/共通の」、andare + 過去分詞「〜されねばならない」、dar retta a)を1本に1〜2個 |
| OMIT | 列挙の第3項以降・挿入節など、訳し落としやすい要素を置く |
| ADD | 原文にない因果・強調を補いたくなる簡潔な言い回しを置く(逆に、補えば誤りになる) |

## 5. 語彙(vocab)の基準

- 1本あたり **5〜8語**。多すぎると本文を読まずに語注で訳せてしまう。
- `hint` は必ず `辞書を引くべき` または `推測可` のいずれか(validate.mjsで検証)。
- 「辞書を引くべき」= 文脈から誤った意味を推測しやすい語・成句(多義語、文法的成句)。「推測可」= 日本語話者が語形・文脈から到達できる語。
- **本文に現れない語をvocabに入れない**。表記は本文中の形か不定詞/単数形の見出し形のどちらかに統一する。

## 6. 検品チェックリスト

生成された1本ごとに、上から順に実施する。**1つでも×があればそのパッセージは破棄または修正**。検品結果はコミットメッセージに `checked: 6/6` の形で残す。

### A. 機械検証(自動)

- [ ] `node content/validate.mjs` が対象ファイルで PASS(exit code 0)
- [ ] WARN が出た場合、レンジ逸脱が意図的かを判断し、意図的でなければ修正

### B. 文法・自然さ(人・全文音読が原則)

- [ ] 動詞の活用・時制の一致(特に遠過去と半過去、接続法の時制の照応)に誤りがない
- [ ] 形容詞・過去分詞の性数一致がすべて正しい(MODの罠が「誤り」になっていないか)
- [ ] 前置詞と冠詞前置詞(del/nel/dal…)の選択が正しい
- [ ] 代名詞の指す相手が**文法的に一意に決まる**(曖昧なだけの文になっていない。難しさは構文由来であるべきで、悪文由来であってはならない)
- [ ] 母語話者が書かない言い回し・直訳臭のある表現がない
- [ ] 自信のない構文を使っていない(**迷ったら平明な構文に書き換える**。これは難度の妥協ではない)

### C. 難度(人)

- [ ] W と Lmax が §3 のフェーズ目標内
- [ ] S(rel+subの平均)と最長文の従属節数が §3 の目標内
- [ ] 最長文が「長いだけ」でなく、入れ子または挿入によって長い
- [ ] 語彙が B1〜B2 の範囲を超えていない(専門用語が3語を超えていない)
- [ ] §4 の必須文法要素が全て入っている(ジャンル別を含む)

### D. 内容・独自性(人)

- [ ] **既存作品の複製・翻案でない**(出典4作品の内容・筋・特徴的な言い回しをなぞっていない)
- [ ] 固有名詞は実在の人物・団体への言及を含まない(架空の人名は可)
- [ ] 事実の主張を含む場合、一般教養の範囲で正しい(検証できない断定を書かない)
- [ ] 企業案件・私的情報の混入がない(公開リポジトリのため)
- [ ] 絵文字が含まれていない(validate.mjs でも検出)

### E. スキーマ整合(人・機械の両方)

- [ ] `sentences[].text` を順に連結すると `text` になる(validate.mjs が語数合計で検出)
- [ ] `clauses[].span` が**実際に数えた語インデックス**であり、切り出した範囲が `note_ja` の説明と一致する(下記コマンドで目視)
- [ ] `skeleton.mainVerb` / `subject` が、挿入句を全て外した後の骨格と一致する
- [ ] `model_ja` を連結したものが `model_ja_full` と齟齬しない
- [ ] `traps` が実際にその文に仕込まれている(付けただけになっていない)

span の目視確認コマンド:

```bash
node -e 'import("node:fs").then(fs=>{const d=JSON.parse(fs.readFileSync(process.argv[1],"utf8"));
d.sentences.forEach(s=>{const w=s.text.trim().split(/\s+/);
s.clauses.forEach(c=>console.log(`s${s.idx} [${c.span}] ${c.type}: ${w.slice(c.span[0],c.span[1]+1).join(" ")}`));});});' content/passages/<file>.json
```
